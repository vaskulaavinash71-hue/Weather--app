# 🌤️ Weather App - Real Time Weather

🔗 **Live Demo:** [Click Here to View App](https://weather-app-xxx.vercel.app)
👨‍💻 **Portfolio:** https://vaskulaavinash71-hue.github.io/portfolio/

Search any city in the world and get live temperature & wind speed instantly.

### ✨ Features
- 🌍 Search any city - Hyderabad, London, New York
- 🌡️ Live Temperature in °C
- 💨 Wind Speed
- 📱 Fully Responsive - Works on Mobile & Desktop
- ⚡ No API Key Required - Uses Free Open-Meteo API

### 🛠️ Tech Stack
- HTML5
- CSS3 (Glassmorphism UI)
- JavaScript (Async/Await, Fetch API)
- Open-Meteo Geocoding API + Weather API

### 🚀 How It Works
1. User enters city name
2. Geocoding API converts city -> Latitude/Longitude
3. Weather API fetches current weather for that location
4. UI updates instantly
